AdmitAction required proofs:
- Capability, Authority, Policy, ExactAuthorization, ActionAdmission
  trust_chain.rs:632-638

Pre-dispatch command proof:
- ExecutionPermit only
  trust_chain.rs:639-643

Current-root upstream revalidation:
- reverify_bound_execution_authorization loads only exact_authorization_proof_id
  postgres_authority.rs:1611-1681

Current command proof validation:
- verifies only proof kinds required by the current command
  postgres_authority.rs:1557-1608

Attack sequence:
1. AdmitAction under root v1.
2. Rotate to root v2 and revoke Capability/Authority/Policy issuer key.
3. Keep ExactAuthorization and ExecutionPermit issuers active.
4. Submit fresh ReserveExecution permit.
5. Old Admission is still executable because only ExactAuthorization + current ExecutionPermit are verified.
